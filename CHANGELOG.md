## 0.1.0

- Initial skeleton.
- `AnchorTarget` with `resolver`, `point`, `rect`, `widget` resolvers.
- `BubbleAnchor` (auto / named / edge / fractional) for connector origin on the bubble.
- `Placement` (auto / angle / fixed side) for bubble position.
- `Arrival` (auto / forced angle) for the connector's target-arrival direction.
- `Connector` with line / curve / elbow / tapered / dotted / none / custom painters.
- `AnchorScope` + `Anchorable` widgets; chart-point example.
